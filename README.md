# KAZA - AI Trip Planning Platform

## Project Description
AI-powered trip planning platform that generates customized trip recommendations based on user preferences.

## Local Setup Instructions
1. Clone the repo or copy from /data/.openclaw/workspace/projects/kaza/kaza-app
2. Copy .env.example to .env.local and fill in Supabase keys
3. Run `npm install`
4. Run `npm run dev`

## Environment Variables Needed
See .env.example

## How to Run Dev Server
`npm run dev` -- opens at http://localhost:3000
